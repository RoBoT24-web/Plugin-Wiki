# Vehicle Build Restrictor

Repository: [RoBoT24-web/Vehicle-Restrictions-Plugin](https://github.com/RoBoT24-web/Vehicle-Restrictions-Plugin)

## What it covers

- Create permission groups with per-item build caps
- Set or remove item limits per group
- Bypass permissions for the global vehicle-building block or all restrictions
