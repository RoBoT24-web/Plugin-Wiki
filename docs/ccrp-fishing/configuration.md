# CCRP Fishing: Configuration

Configuration options for the CCRP Fishing plugin include:

- **Fishing rod tiers**: Quality levels and their properties
- **Catch rates**: Probability settings for successful fishing
- **Fish loot tables**: Weighted distribution of fish types
- **Item IDs**: Specific configuration for fishing-related items

See: [RoBoT24-web/CCRP-Fishing](https://github.com/RoBoT24-web/CCRP-Fishing)
