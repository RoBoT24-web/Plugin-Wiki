# RoBoT24 Plugin Wiki

Central documentation for staff and server admins: commands, permissions, and short descriptions for each plugin, in one place.

<div class="grid cards" markdown>

- :material-shield-account: **[CCRP Plugin](ccrp/index.md)**

    Moderation, staff tools, items/vehicles, blacklists and Wrecking Ball.

- :material-account-police: **[CCRP Police](ccrp-police/index.md)**

    Police-focused tools and role support for staff and enforcement gameplay.

- :material-fishing: **[CCRP Fishing](ccrp-fishing/index.md)**

    Tiered fishing rods, catch chances and weighted fish loot.

- :material-garage: **[RFGarage](rfgarage/index.md)**

    Personal vehicle garage with admin tools and storage migration.

- :material-car-wrench: **[Vehicle Build Restrictor](vehicle-build-restrictor/index.md)**

    Permission groups with per-item vehicle build caps.
