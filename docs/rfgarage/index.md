# RFGarage

Repository: [RoBoT24-web/RFGarage-master](https://github.com/RoBoT24-web/RFGarage-master)

## What it covers

- Store the current or targeted vehicle in a personal garage
- List and retrieve stored vehicles
- Admin tools to list, wipe or delete another player's garage
- Storage backend migration
- Slot limits, auto-store for drowned vehicles, and blacklist bypass permissions
